## 3. Justificación Técnica Formal de la Selección

**Stack seleccionado: Python / FastAPI + React + PostgreSQL + Leaflet/OpenStreetMap**

### 3.1 Razones principales

1. **Metaheurísticas y cómputo científico**  
   Python dispone del ecosistema más maduro y productivo para implementar Algoritmos Genéticos, Búsqueda Tabú y Optimización por Colonia de Hormigas (DEAP, OR-Tools, NumPy, SciPy). Esto es crítico para cumplir RNF-001 (≤ 45 s).

2. **Rendimiento y consumo de recursos**  
   FastAPI es asíncrono, de bajo consumo de memoria y genera documentación OpenAPI automáticamente. Ideal para un presupuesto limitado y criterios de eco-diseño.

3. **Alineación con el equipo**  
   El equipo ya posee conocimientos intermedios de Python y desarrollo web. La curva de aprendizaje es manejable dentro de las 14 semanas.

4. **Base de datos relacional**  
   PostgreSQL ofrece integridad referencial, soporte geoespacial (PostGIS) y excelente rendimiento para consultas de rutas y reportes. Cumple con la necesidad de datos estructurados (flota, pedidos, conductores, ventanas de tiempo).

5. **Frontend y mapas**  
   React + Leaflet/OpenStreetMap permiten una SPA moderna, responsive y de bajo consumo de datos (importante para RNF-009 – conectividad 2G/3G). Evita costos de Google Maps API en el MVP.

6. **Restricciones del proyecto**  
   Cumple estrictamente con C-03 (tecnologías prioritarias de código abierto) y con el presupuesto fijo de S/ 500 000.
