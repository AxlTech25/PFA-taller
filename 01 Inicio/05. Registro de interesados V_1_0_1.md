## 3. Estrategia de Gestión y Comunicación

| Grupo / Interesado | Frecuencia de comunicación | Formato / Canal | Tipo de información a entregar |
|---|---|---|---|
| I-01 (Gerente de Operaciones) | Semanal | Dashboard y reportes PDF (RF-005, RF-006) | Ahorro de combustible, métricas de CO₂ y costos operativos |
| I-02 (Conductores) | Diaria / Tiempo real | Aplicación web – Modo Conductor (RF-005) | Rutas asignadas, alertas de tráfico y zonas de riesgo |
| I-03 (Clientes) | Por pedido | Notificación web in-app / correo electrónico | Ventana de tiempo estimada de entrega |
| I-04 (Docente) | Por iteración | Repositorio GitHub / Exposición | Entregables técnicos, arquitectura y avances del MVP |
| I-05 (Equipo de Desarrollo) | Diaria (daily) y por iteración | Reunión de equipo / Repositorio GitHub | Avance de tareas, impedimentos y control de cambios |
| I-06 (Operador de Logística) | Diaria / Tiempo real | Interfaz web de operación (RF-002, RF-003, RF-007) | Pedidos pendientes, rutas generadas e incidencias |
| I-07 (Administrador del Sistema) | Semanal / ante incidentes | Panel de administración (RF-011, RF-012) | Usuarios y roles, parámetros del algoritmo, logs de auditoría |
| I-08 (Autoridades de Tránsito) | Ante cambios normativos | Publicaciones oficiales (consulta) | Restricción vehicular, normativa de tránsito y de transporte de carga |
| I-09 (Proveedores de APIs) | Continua (bajo demanda) | API REST / documentación técnica | Datos de tráfico, incidentes y mapa base |

---

## 4. Nota de Coherencia

Los canales de notificación al cliente (I-03) se limitan, dentro del alcance del MVP, a **notificaciones web in-app y correo electrónico**. El envío por SMS queda fuera del alcance del MVP por su costo y por la restricción presupuestal C-01 del documento *04. Registro de supuestos y restricciones*.
